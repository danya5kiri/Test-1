# CREACLOUD Redesign Preview

Отдельная тестовая версия мобильного и десктопного интерфейса CREACLOUD для
креаторской студии «Корсар».

Проект не связан с действующим сайтом, Google Apps Script или рабочей таблицей.
Все тестовые действия сохраняются только в `localStorage` текущего браузера.

## Реализовано

- стартовая анимация и выбор статуса участника;
- адаптивный плиточный дашборд;
- модальные окна на мобильном и десктопе;
- календарь, создание, перенос и отмена тестовой брони;
- личный кабинет по нику;
- статистика, достижения и рекомендация тура;
- добавление контента;
- рейтинги, итоги и просмотр публикаций;
- безопасный сброс демо-данных.

## Запуск

Требуется Node.js 22.

```bash
npm ci
npm run dev
```

Проверка production-сборки:

```bash
npm test
```

## Публикация
