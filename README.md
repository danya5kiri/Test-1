# CREACLOUD Test-1

Отдельный мобильный и десктопный интерфейс CREACLOUD для креаторской студии
«Корсар».

`Test-1` опубликован отдельно от основного сайта, но подключён к тому же рабочему
Google Apps Script. Бронирования, переносы, отмены и материалы, созданные здесь,
попадают в общую рабочую базу. Локальный кэш и защита от повторной отправки
используют отдельные ключи `creacloud-test-1-*` и не пересекаются с основным
интерфейсом.

## Реализовано

- стартовая анимация и выбор статуса участника;
- адаптивный плиточный дашборд;
- автокарусель трёх лидеров: поездки, уникальные туры и контент;
- модальные окна на мобильном и десктопе;
- полное расписание сезона с апреля по октябрь;
- создание, перенос и отмена рабочей брони;
- личный кабинет по нику;
- статистика, достижения и рекомендация тура;
- добавление контента в общую базу;
- рейтинги, итоги и просмотр публикаций;
- погодный информер Владивостока;
- отдельный локальный кэш последнего успешного чтения.

## Запуск

Требуется Node.js 22.

```bash
npm ci
npm run dev
```

Проверка production-сборки:

```bash
npm test
```

## Публикация

GitHub Actions автоматически собирает и публикует ветку `main` в GitHub Pages.
Сайт разворачивается по адресу:
`https://danya5kiri.github.io/Test-1/`.
