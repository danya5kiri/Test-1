# CREACLOUD

Кабинет креаторов морской студии «Корсар».

## Возможности

- календарь туров и прогноз погоды по выбранной дате;
- бронирование, перенос и отмена записи;
- вход в личный кабинет по нику после первой брони;
- персональная статистика, достижения и рекомендации;
- добавление готового контента;
- рейтинги по поездкам, уникальным турам и материалам;
- итоги, фильтры и просмотр публикаций;
- ежедневная сводка последних событий;
- адаптивные модальные окна и мобильная навигация.

Бронирования и публикации синхронизируются с общей базой CREACLOUD. Локальное
хранилище используется только для кэша интерфейса и защиты от повторной
отправки одной операции.

## Локальный запуск

Требуется Node.js `>=22.13.0`.

```bash
npm ci
npm run dev
```

Проверки:

```bash
npm run lint
npm run build
```
